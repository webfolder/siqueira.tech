{%- comment -%} Add Multilanguage support If you want to use multilanguage, you have to add the following fields at the target file header. For example: --- title: A cool title lang: en ref: acoolref layout: default --- The ref parameter is responsible for group all related file with the specific language. Note: lang and ref are mandatory if you want to use multilanguage {%- endcomment -%}
